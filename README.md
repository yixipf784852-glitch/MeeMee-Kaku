# 咩咩制卡台（MeeMee-Kaku）

把一部作品的资料做成一张能导进 SillyTavern（酒馆）玩的角色卡；导进去玩不了的旧卡，也能在这里修好。

生成用的模板照《咩咩制卡预设》原文，做出来的卡和咩咩预设配套。

## 功能特点

- **出卡流水线**：填作品名、资料和角色清单，一键生成角色、设定、地点、世界规则、时间线、状态栏、话题池、开场白，自动装进同一张卡。
- **零件台**：一次只写一件；写出好几条时挑着装，没挑的留在历史里；不想配接口，也能复制完整提示词，拿到别的聊天工具里生成，再贴回来装进卡。
- **核心设定**：可以选拆成几条，也可以只出一条。
- **修卡台**：拖进一张玩不了的卡，当场告诉你哪儿坏了、把结构修好，逐条列出改了什么；正文不合模板的，可以照模板重写，写好了挑着装回去。
- **条目随手改**：每条世界书都能改名、改关键词（支持正则）、改顺序、位置、深度、概率，也能删掉，删错了能撤销。
- **格式检查分两档**：会让 AI 犯迷糊的问题单独列出来；只是写法不合咩咩模板的，收在折叠里，不吓人。
- **时间线**：原著人物照写原名；体量小的作品可以一次写完整条时间线；长篇可以分段写，后一段接着前一段往下排。
- **拿走**：下载 PNG 角色卡、角色卡 JSON、世界书 JSON，能直接导进酒馆。
- **三种用法**：电脑上双击网页就能用；也有 Windows 桌面版和安卓手机版。

## 安装

**网页版**：双击 `咩咩制卡台.html`，用 Chrome 或 Edge 打开。

**Windows 桌面版**（二选一）：

1. 安装版 `MeeMee-Kaku-版本号-setup.exe`：双击，按提示装好，以后从开始菜单打开。
2. 免安装版 `MeeMee-Kaku-版本号-portable.exe`：双击就能用，每次启动慢几秒。

第一次打开，Windows 可能提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。

**安卓**：把 `MeeMee-Kaku-版本号.apk` 传到手机上点开安装。手机会让你允许「安装未知应用」，apk 是从哪个应用点开的（QQ、文件管理……），就给哪个应用开这个权限。

## 快速开始

装好以后，第一次就能做出一张卡。**第一次使用要先在顶栏「接口」里填好接口地址、密钥和模型。**

1. 打开咩咩制卡台，点顶栏的「接口」，填地址、密钥，点「读取模型」选一个，保存。
2. 「出卡流水线」第 ① 步：填作品名，贴一段原作资料，角色清单一行写一个名字。
3. 点「建立工程，开始盘点」，再点「一键出卡」，看一眼清单，点开跑。
4. 等三波跑完，到第 ⑤ 步点「下载 PNG」。
5. 在酒馆里「角色管理 → 导入」选这张 PNG，就能开始玩。

## 使用说明

### 从零做一张卡

1. 第 ① 步填作品名、卡名、原作资料和角色清单。资料越具体，写出来越贴原作。
2. 第 ② 步看这张卡现在有什么、缺什么。
3. 点「一键出卡」，确认要生成的件和并发数，开跑。生成分三波，后面的件会参考前面写好的。
4. 第 ③ 步看进度。没通过格式检查的件标黄，点开能手改，也能单独重写。
5. 第 ④ 步整理结构：确认每条的分区，点「整理结构」。
6. 第 ⑤ 步下载，导进酒馆。

### 在零件台写一件

1. 点顶栏「零件台」，左边选模板。
2. 填零件名称，把这件要用的资料贴进「这件的专属资料」。
3. 核心设定可以在「出几条」里选「只出一条」；想只写某一个设定，就把它的名字填在零件名称里。
4. 点「生成这一件」，看一眼输出，点「装进当前卡」。
5. 写出好几条时会弹框，勾上要的再装；同一件装第二次，会问你换掉上次的还是另装一份。

### 长篇时间线分段接着写

1. 先照常写第一段，比如第 1-200 章，装进卡。
2. 出卡流水线第 ② 步，时间线那一行点「接着写」（也可以在零件台把「生成范围」选成「接着卡里的时间线往下写」）。
3. 选接在哪条后面，把下一段原文（比如第 201-400 章）贴进专属资料。
4. 点「生成这一件」，再点「装进当前卡」。新的一段会并进原来那条时间线，日期和事件编号自动接着排。
5. 还有下一段就重复第 2~4 步。

### 修一张玩不了的卡

1. 点顶栏「修卡台」，把 PNG、JSON 卡或世界书拖进去。
2. 看第 02 步：哪些是「重」（不修玩不了），哪些只是写法不合咩咩模板。
3. 看第 03 步：结构已经当场修好，表里能逐条看改前改后，男女分区猜错了可以改。
4. 第 04 步：缺的件点「让 AI 写」；正文不合模板的，点「照模板重铸」，写好后勾上要的，点「装进卡里」。
5. 第 05 步下载，或者送进出卡流水线接着补。

### 改一条世界书

1. 出卡流水线第 ④ 步，找到那一条。
2. 点右边的 ⚙，改名、关键词、顺序、位置、深度、概率、防递归，或者上移下移。
3. 点右边的 ✕ 删掉；删错了，趁提示还在点「撤销」。

### 导进酒馆

1. 酒馆里走「角色管理 → 导入」，选下载的 PNG。不要直接把 PNG 拷进 characters 文件夹。
2. 酒馆问要不要导入内嵌世界书，选导入。
3. 在角色页打开「更多 → 链接到世界书」，确认绑的是这张卡的世界书。

## 设置

顶栏「接口」：

| 设置 | 说明 |
|---|---|
| 接口地址 | 任何兼容 OpenAI 格式的接口，填到 `/v1` 为止 |
| 密钥 | 只存在你自己的电脑或手机上，不会写进导出的卡 |
| 模型 | 点「读取模型」从列表里选，或者直接填名字 |
| 温度 | 默认 0.8，越高越发散 |
| 最大输出 | 一次最多写多少；一次性输出整条时间线时可以调大 |
| 流式输出 | 边写边显示（安卓版要写完才一起显示） |

## 兼容性

| 平台 | 最低要求 | 原因 |
|---|---|---|
| Windows 桌面版 | Windows 10 64 位 | 桌面版基于的运行环境不再支持更老的系统 |
| 安卓 | 安卓 7.0，系统 WebView 98 以上 | 页面用到了较新的网页功能；WebView 太旧可能用不了，在应用商店更新「Android System WebView」 |
| 网页版 | Chrome 或 Edge 98 以上 | 同上 |
| iOS | 暂不支持 | 没有做苹果手机版 |

## 常见问题

**网页版连不上接口，桌面版却可以？**
有些服务商不让网页直接带密钥访问。换桌面版或安卓版就行；非要用网页版，用同目录的 `接口代理.py` 在本机套一层。

**安卓版为什么不是边写边显示？**
手机版的请求走手机自己的网络通道，这样才不会被拦，代价是回复要整段写完才一起出来。写长东西时多等一会儿。

**格式检查报了一堆，卡还能玩吗？**
能。「要看一眼」那档才可能让 AI 犯迷糊，比如时间线日期写错、事件编号重复；折叠里的只是写法不合咩咩模板，不影响导入和游玩。

**存档在哪？换电脑、换手机怎么办？**
网页版存在浏览器里，桌面版和安卓版存在程序自己的数据里，三者不互通。换设备前，先下载 PNG 或 JSON，到新设备上再导入。安卓版卸载会把存档一起删掉。

**导进酒馆后世界书没生效？**
在角色页打开「更多 → 链接到世界书」，手动绑一次。
